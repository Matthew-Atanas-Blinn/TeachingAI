## User-Defined Functions Module Index

Read:
- `source_of_truth.md` for any work involving user-defined functions;
- `review_checklist.md` when generating or reviewing slides, quizzes, assignments, examples, or other dependent artifacts; and
- `decisions.md` when reconsidering the module sequence, parameter mental model, return-value preference, or scope boundaries.

Use this module for work involving:
- function motivation and decomposition;
- declarations, definitions, and calls;
- arguments and parameters;
- value, reference, and const-reference parameters;
- return values and `void` functions;
- scope, lifetime, static locals, side effects, and global state;
- driver programs, stubs, and function testing;
- function overloading; and
- default arguments.
