## Balanced Trees Module

### Status

Decision stub only. This module has not yet been fully designed.

### Approved direction

Balanced trees should be introduced while teaching binary search trees rather than treated as an unrelated later topic. Students should understand that BST operations depend on height, unfavorable insertion order can produce linear height, balanced trees limit height, and rotations can restore balance while preserving BST ordering. Conceptual understanding and representative rotation tracing are the current default; a full AVL or red-black implementation is not currently required.

### Required before substantial module development

Complete the learning objectives, prerequisites, selected balancing scheme, rotation depth, implementation expectations, complexity expectations, example set, misconceptions, assessment scope, review checklist, and source of truth before generating substantial module materials.

### Routing

Use this folder for BST degeneration, balanced search trees, AVL trees, rotations, and the relationship between balance and operation complexity.
