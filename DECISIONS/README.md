# Accepted Decisions

Use this folder for consequential, accepted decisions whose rationale should survive beyond the file that implements them.

Recommended record:

```markdown
# Decision: Short title

Status: Accepted
Date: YYYY-MM-DD
Scope: Repository | Course | Module | Artifact type

## Context
## Decision
## Benefits
## Drawbacks
## Assumptions
## Alternatives considered
## Consequences
## Files implementing the decision
## Revisit when
```

Do not create a decision record for every minor edit. Use one when future users will reasonably ask why the system works this way or when alternatives have meaningful tradeoffs.
