# Programming Fundamentals II (COSC 1437)

Status: Preliminary course-level context. Do not infer a complete curriculum from this file.

## Learner context

Students are transitioning from procedural programming toward object-oriented design, dynamic resources, inheritance, polymorphism, templates, and larger multi-file programs. Materials should connect new abstractions to the concrete object state and lifetime behavior beneath them.

## Durable approach

- Use interfaces and harnesses to isolate the concept being assessed.
- Require students to choose important design features when those choices are objectives, such as virtual functions, virtual destructors, or inheritance visibility.
- Prefer instructor-provided headers plus student `.cpp` implementations when that preserves the learning objective and simplifies reliable grading.
- Test resource ownership, copy behavior, destruction, and dynamic dispatch independently where practical.
- Avoid allowing one compile/link defect to erase evidence of unrelated understanding during recovery review.

## Quiz context

Use Foundation -> Tracing -> Application -> Integration -> Design/Diagnosis. Tracing object lifetime, pointers, copy behavior, and virtual dispatch should be represented where they match the module.
