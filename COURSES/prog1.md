# Programming Fundamentals I (COSC 1436)

Status: Preliminary course-level context. Expand as the course redesign stabilizes.

## Learner context

Students are beginning programming and need explicit support connecting syntax, values, control flow, and problem solving. Examples should minimize incidental complexity while still requiring meaningful reasoning.

## Durable approach

- Motivate concepts with concrete problems or limitations.
- Emphasize tracing and prediction before independent creation.
- Build accurate mental models rather than memorized syntax alone.
- Keep introductory input/output grading focused primarily on obtaining the correct result.
- Prefer prompts/specifications that are precise enough to autograde but do not over-penalize harmless wording differences unless exact output is an objective.

## Established introductory I/O weighting default

For appropriate introductory programs:

- 75%: correct result, allowing minor wording differences;
- 20%: reasonably correct prompts or labels, distributed across required labels;
- 5%: completely exact output.

This is a default for suitable assignments, not a universal rubric.

## Quiz context

Students complete substantial programming assignments, so quizzes may emphasize conceptual foundations, tracing, and diagnosis rather than duplicating full program construction. Use the standard 16-8-8-6-2 distribution when appropriate.

## File and environment context

- C++
- Blinn D2L eCampus
- Students submit individual required files unless an assignment explicitly differs.
- Autograding uses the established pipeline and relative paths.
