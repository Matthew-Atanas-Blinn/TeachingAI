# Global Standards Index

Global standards apply across more than one artifact type. Load a file whenever its trigger matches the current task.

- `cpp_instruction.md`: read whenever generating, reviewing, or modifying C++ instructional content, examples, starter code, tests, interfaces, or grading expectations.
- `visual_mapping.md`: read whenever an artifact visually maps explanations to code, diagrams, formulas, states, categories, or other regions.
- `review_checklist.md`: read during final review whenever one or more global standards applied.

Do not load a standard merely because it exists. Apply its stated trigger.
