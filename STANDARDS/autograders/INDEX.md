# Autograder Standards Index

For every autograder creation, revision, testing, or review task, read:

- `generation.md`
- `review_checklist.md`

Also read `assignment_pipeline_integration.md` when the task creates, revises, packages, converts, validates, grades, troubleshoots, or maintains a C++ assignment or autograder that uses Matthew's Assignment Pipeline, including `run_pipeline.py`, `gio.py`, pipeline `rubric.json` files, pipeline `cases/`, pipeline harnesses, or pipeline-generated grading results.

Do not load `assignment_pipeline_integration.md` for a general autograding discussion or for another grading implementation unless comparison or migration requires it.

This index owns the trigger. The integration file defines the contract after this index selects it.
